# 闪点行动：重制版 战役汉化

用于《闪点行动：重制版》的战役汉化文件。重制版原生支持 UTF-8，而旧版汉化战役多为 GB2312 编码，无法直接使用；本仓库提供对应的汉化文件以便替换使用。

## 背景

- 本项目基于《闪点行动：重制版》进行战役汉化。重制版请从 Steam 获取；购买过《Cold War Assault》的玩家可以免费获得重制版。
- 重制版原生支持 UTF-8，但旧的汉化战役文件（例如天人互动的《冷战危机》《抵抗力量》，以及其他制作时间早于 2026 年的汉化任务/战役）通常使用 GB2312 编码，因此不能直接使用。

## 使用方法

1. 从可靠渠道获取**原始**战役文件。
2. 解包战役文件（通常为 `.pbo`），将解包后的目录放入 **Campaigns** 目录。
   - 重制版的两个官方战役本身没有打包，无需解包。
   - 很多经典 OFP 战役可从 [这个页面](http://user.qzone.qq.com/758048929/blog/1351915056) 下载。
3. 从本仓库下载对应的战役汉化文件，放入 **Campaigns** 目录，替换原始解包战役文件中的同名文件。
4. 无需再次打包为 `.pbo`，可以直接游玩。

## 汉化制作与提交

- 基于 `agents.md`，指定目录，让智能体对指定战役进行汉化。
- 建议在测试通过后再提交代码。
